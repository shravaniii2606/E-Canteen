# School Canteen Management System

A fullstack web application for managing a school 
canteen. Built this as a real-world project to 
handle canteen operations like menu management, 
orders, and user signup with proper validation.

## Live Demo

https://canteen-e7h0.onrender.com/


## Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Python, FastAPI
Database: PostgreSQL
Deployed on: Render

## Features

User signup with schema validation,
Menu browsing and order management,
Token generation for each order,
Real-time data handling via REST APIs,
Organized multi-page frontend structure,
Database with proper schema and seed data.


## What I learned

Structuring a fullstack project properly,
PostgreSQL schema design and seed data,
FastAPI with schema validation using Pydantic,
Organizing a multi-page frontend,
Deploying a fullstack app on Render.
